# أداة Ghost Radar

## 🌟 نبذة عن الأداة
أداة **Ghost Radar** هي أداة فحص شبكات واستطلاع (Reconnaissance) متقدمة وسريعة تعتمد على Python، صُممت ببنية معيارية (Modular Architecture) تجمع بين سهولة التطوير، التشفير القوي للبيانات، ووضع التخفي (Ghost Mode) لحماية خصوصيتك أثناء الفحص.

---

## ✨ المميزات الرئيسية

* **دعم كامل للغة العربية في التيرمنال:** عرض سليم للأحرف العربية من اليمين لليسار عبر ملف `arabic_tools.py` ومكتبات `arabic_reshaper` و `python-bidi`، مع دعم التبديل الفوري بين العربية، الإنجليزية، والتركية.
* **وضع الشبح (Ghost Mode):** تمويه حركة الشبكة عبر عناوين MAC عشوائية، تأخير زمني موزع طبيعياً (Poisson Delay)، إخفاء اسم العملية، ودعم تمرير الاستعلامات عبر Tor / SOCKS أو عزلها كلياً.
* **تشفير البيانات والخزنة (AES-256-GCM Vault):** جميع السجلات والتقارير المحفوظة (JSON / HTML) تُشفّر تلقائياً بمفتاح مرتبط ببصمة الجهاز عبر HMAC لضمان عدم كشف أي عناوين أو بيانات شبكة كنص صريح.
* **فحص الشبكة المحلية (ARP Scanner):** اكتشاف الأجهزة المتصلة، عناوين MAC، الشركات المصنّعة، وتخمين نظام التشغيل عبر بصمة TTL، مع تنبيه فوري عند ظهور أجهزة جديدة أو اختفاء أجهزة سابقة.
* **استطلاع المواقع والسيرفرات (Web Recon):** فحص الموقع الجغرافي، مزود الخدمة (ISP)، شهادات SSL/TLS، الترويسات الأمنية المفقودة، سجلات DNS (مع دعم DoH عبر البروكسي)، واكتشاف النطاقات الفرعية عبر Certificate Transparency.
* **فحص المنافذ العميق والثغرات (Deep Port & CVE Scanner):** مسح SYN خفي، جلب بصمات الخدمات (Banner Grabbing)، والتحقق التلقائي من الثغرات المعروفة عبر قاعدة NVD الرسمية.

## 🔐 فك تشفير التقارير والسجل (Unseal)

كل ما يكتبه البرنامج (`ghost_radar_report_*.json`، `ghost_radar_report_*.html`، و `ghost_radar_history.json`) مشفّر تلقائياً بخوارزمية **AES-256-GCM** باستخدام مفتاح الخزنة المحفوظ محلياً في:

* **Linux / macOS:** `~/.ghost_radar/vault.key`
* **Windows:** `C:\Users\<اسمك>\.ghost_radar\vault.key`

يمكنك فك التشفير بطريقتين:
1. **من داخل البرنامج مباشرة:** اختر الخيار رقم `8` من القائمة الرئيسية (فك تشفير تقرير/سجل محفوظ)، وسيتم حفظ نسخة مفكوكة بجانب الملف الأصلي باسم `<الاسم>_decrypted`.
2. **عبر المتصفح (لتقارير HTML):** افتح ملف التقرير `.html` في المتصفح والصق قيمة مفتاح الخزنة (Base64 من ملف `vault.key`) لفك تشفيره وعرضه داخل إطار معزول وآمن.

> **ملاحظة:** المفتاح مربوط ببصمة الجهاز عبر HMAC؛ لنقل التقرير وفتحه على جهاز آخر، ستحتاج إلى نسخ ملف `vault.key` معه.

## ⚙️ متغيرات البيئة (Environment Variables)

يمكنك التحكم في سلوك الخصوصية والاتصال قبل تشغيل `main.py` عبر ضبط المتغيرات التالية:

| المتغير | الوظيفة |
| :--- | :--- |
| `GHOST_NO_EXTERNAL=1` | منع أي اتصال بالخدمات الخارجية نهائياً (عزل تام) |
| `GHOST_PROXY=socks5h://127.0.0.1:9050` | تمرير الاستعلامات الخارجية وحل DNS عبر Tor أو بروكسي |
| `GHOST_NO_BANNER=1` | منع جلب بصمات الخدمات (Banner Grabbing) نهائياً |
| `GHOST_ALLOW_BANNER=1` | السماح بجلب البصمات حتى أثناء تفعيل وضع الشبح |
| `GHOST_ALLOW_DIRECT_TLS=1` | السماح بفحص شهادة SSL مباشرة في وضع الشبح بدون بروكسي |
| `GHOST_PLAINTEXT_FILES=1` | السماح بحفظ التقارير والسجل كنص صريح إذا لم تتوفر مكتبة cryptography |
