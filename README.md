# أداة RADAR
## 🌟 نبذة عن الأداة
أداة **RADAR** هي أداة فحص شبكات واستطلاع (Reconnaissance) مبسطة وسريعة تعتمد على Python. تتيح للمستخدمين فحص الشبكات المحلية، سحب بيانات الخوادم، والبحث عن المنافذ المفتوحة بكل سهولة.

## ✨ المميزات
*   **دعم كامل للغة العربية في التيرمنال (موجه الأوامر)!** 🇸🇦 (يدعم العرض الصحيح للأحرف العربية من اليمين لليسار بفضل مكتبات `arabic_reshaper` و `python-bidi`).
*   **فحص الشبكة المحلية (ARP Scanner):** اكتشاف الأجهزة المتصلة، عناوين الماك، وتخمين نوع نظام التشغيل.
*   **استطلاع الخوادم والمواقع (Banner Grabbing):** جلب معلومات الموقع الجغرافي، الـ IP، ومزود الخدمة (ISP).
*   **فحص المنافذ العميقة (Deep Port Scanner):** مسح المنافذ الشائعة ومعرفة حالتها (Open, Closed, Filtered).
*   **دعم ثنائي اللغة:** يمكن التبديل بين العربية والإنجليزية في أي وقت.

## ⚠️ إخلاء المسؤولية
> **تنويه هام:** هذه الأداة قابلة للتطوير والتوسعة بشكل ملحوظ جداً نظراً لبساطة الكود البرمجي الخاص بها. تم تصميمها للأغراض التعليمية واختبار الاختراق الأخلاقي فقط. يُرجى استخدامها فقط على الشبكات والأنظمة التي تمتلك تصريحاً صريحاً لاختبارها.

## 🛠️ المتطلبات والتثبيت

1. قم بتثبيت المتطلبات الأساسية عبر الملف المرفق:
```bash
pip install -r requirements.txt
```

2. قم بتشغيل الأداة (يُفضل بصلاحيات الـ Root لضمان عمل فحص ARP بشكل صحيح):
```bash
sudo python3 main.py
```
